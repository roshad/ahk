- [x] 保留ahk原本的托盘右键重载等功能。
- [x]  有一个最大化的面板。
- [x]  面板中有一个添加文本的按钮。
    - [x]  点击按钮后，弹出一个多行输入框，用户可以输入文本。文本可以有标题。
    - [x]  输入文本后，可以保存到面板中。
- [x]  面板中一些显示保存了的文本内容的按钮。
    - [x] 有标题，则只显示标题。
    - [x] 点击后，粘贴到当前活动窗口。并且关闭面板。
- [x] 默认是 dark mode。
    - [x] 编辑窗口文本编辑区使用暗色背景、浅色文字。

- [x] 支持使用 `Alt+Shift+V` 全局呼出或隐藏面板。
    - [x] 呼出面板前记录当前活动窗口，点击文本后仍能粘贴回该窗口。
    - [x] `Esc` 和窗口关闭按钮只隐藏面板，脚本继续在托盘运行。
    - [x] 托盘菜单可以显示面板、打开数据目录、打开备份目录和退出脚本。
- [x] 支持管理已保存的文本。
    - [x] 右键文本按钮可以编辑标题和正文。
    - [x] 右键文本按钮可以确认删除，并将内容移入应用回收站。
    - [x] 回收站可以恢复、永久删除或清空内容。
- [x] 支持拖动调整文本顺序。
    - [x] 点击“排序”进入排序模式，可以直接拖动主面板中的文本按钮。
    - [x] 松手后立即保存顺序到 `order.txt`。
    - [x] 点击“完成排序”退出排序模式。
    - [x] 使用 `order.txt` 持久保存顺序，重启后保持不变。
    - [x] 兼容没有 `order.txt` 的现有数据。
- [x] 支持分组文本（一层分组网格）。
    - [x] 创建、重命名、删除分组。
    - [x] 分组标题栏和边框右键可以打开分组操作菜单，并提供可见的“操作”按钮。
    - [x] 一层分组显示，数据结构保留 `ParentId` 以兼容未来多层结构。
    - [x] 分组显示为带左上角标题栏的矩形网格。
    - [x] 可设置分组行数和列数，并在超出当前分页容量时拒绝设置。
    - [x] 文本可以拖入分组，也可以拖回未分组区域。
    - [x] 根级分组可以拖动调整同级顺序，禁止分组拖入其他分组。
    - [x] 分组作为完整矩形参与分页，不跨页、不溢出页面边界。
    - [x] 同一页面的分组优先填充横向剩余空间，避免上方出现空位时新分组直接排到下一行。
    - [x] 使用版本化 `layout.ini` 保存分组、父级和顺序，并兼容旧 `order.txt`。
    - [x] 分组容量不足时拒绝放置且不改变原位置。
    - [x] 删除非空分组时按原顺序将内容移到父级或未分组区域。
    - [x] 回收站恢复文本时尝试恢复原分组，分组不存在时回到未分组区域。
- [x] 支持自动备份文本数据。
    - [x] 每天启动时最多创建一次有变化的数据快照。
    - [x] 每次运行首次编辑、删除或保存排序前创建安全快照。
    - [x] 备份采用时间戳目录并只保留最近 10 份。
- [x] 支持设置文本数据的存储位置。
    - [x] 可以选择本地目录或网盘同步目录作为存储根目录。
    - [x] 存储位置保存到本地设置文件，重启后继续使用。
    - [x] 切换到空目录时可以选择复制现有数据。
    - [x] 目标已有数据时可以安全切换，且不会自动覆盖或合并文件。
    - [x] 配置的目录暂时不可用时回退到脚本目录并提示用户。
    - [x] 本地存储路径和运行数据不会提交到 Git。
    - [x] 目录选择器默认从“此电脑”开始，而不是从当前存储目录开始。
